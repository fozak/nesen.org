    SITEMAP CHECKLIST

    ✓  Every indexable page included
    ✓  Noindex pages excluded
    ✓  Components folder excluded
    ✓  URLs match canonical tags
    ✓  lastmod in yyyy-MM-dd format
    ✓  Listed in robots.txt
    ✓  Submitted to Search Console
